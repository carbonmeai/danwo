# File marks

Format marks from [theSVG](https://github.com/glincker/thesvg) (MIT, see `LICENSE-thesvg.txt`), taken at commit f37d140ad52d5cb510fb0430541a6d0359cebf0e9. The Office marks are Microsoft's own icons for Word, Excel and PowerPoint.

| File                             | theSVG icon                   |
| -------------------------------- | ----------------------------- |
| word.svg                         | microsoft-word/default        |
| excel.svg                        | microsoft-excel/default       |
| powerpoint.svg                   | microsoft-powerpoint/default  |
| pdf.svg                          | acrobat-reader/default        |
| markdown.svg / markdown-dark.svg | markdown/light, markdown/dark |
| json.svg                         | json/default                  |
| html.svg                         | html5/default                 |
| xml.svg                          | xml/default                   |
| zip.svg                          | 7zip/default                  |

The marks belong to their owners and are used only to identify file formats.
