# Icon sources

theSVG (https://thesvg.org, repo https://github.com/GLINCKER/thesvg) is MIT-licensed code; each icon
carries its own licence field in `src/data/icons.json`, listed below. Its LEGAL.md says brand marks stay
the property of their owners and are included for identification (nominative fair use), so follow each
brand's guidelines before shipping. logo.dev (img.logo.dev) needs an API token (HTTP 401 without one) and
was not used.

Files ending `-on-dark` are the variant for dark backgrounds. `wordmarks/` holds the logo-wall versions.

## danwo's own brand

The dánwò lockups, mark, favicons and app icons come from the repository's `brand/` folder; the
build copies them to `/brand/` and `/favicon.ico` (see `src/generator/brand.ts`), so edit them only
there. The wordmark is set in Young Serif (SIL Open Font License, `brand/YoungSerif-OFL.txt`) and is
already converted to outlines, so the site ships no font file and needs no copy of the licence.
