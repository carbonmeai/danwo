`danwo serve` opens a dashboard of your project's runs: every test, every matrix, every recording.
It reads what danwo already keeps in `.danwo`, on your machine. Nothing leaves it.

## Open it

```sh
npx @danwo/cli serve --open
```

```text
danwo dashboard for ~/code/shop
http://127.0.0.1:4310/
```

It finds the project from the nearest `danwo.config.ts`. It never writes to `.danwo`, so leave it
open while you run tests and reload a page to see new runs. `-p 0` picks any free port.

## The pages

The sidebar holds every page. Collapse it to icons with `Cmd+B` (or `Ctrl+B`).

| Page     | What it shows                                                                             |
| -------- | ----------------------------------------------------------------------------------------- |
| Overview | pass rate, runs, failed tests and run time over 7, 30 or 90 days, and what's worth a look |
| Tests    | every test with its latest result, pass rate and matrix verdict                           |
| Runs     | every `danwo test` and `danwo matrix` run, filtered by status, kind and date              |
| Matrix   | each test's latest matrix verdict and the faults that broke it                            |
| Insights | flake rate, the slowest and costliest tests, the replay cache, lint findings              |
| Impact   | what each test touched: pages, providers, webhooks                                        |
| Settings | the project folder, the config, and keyboard shortcuts                                    |

## Overview

![The Overview page: pass rate, runs and run time, with trends](/docs/dashboard-overview.png)

The four cards compare the chosen window with the one before. Click a day's bar to see its runs.

## Tests

![The Tests page: each test with its result, pass rate and matrix verdict](/docs/dashboard-tests.png)

Each row shows the matrix's verdict: **breaks under** a fault, **held under all**, or no matrix yet.
**Run selected** and **Run all** start `danwo test` from the page.

## Runs

![The Runs page: every test and matrix run, with its time and model spend](/docs/dashboard-runs.png)

Filter by status, kind and date. A test run lists each test with its attempts; click one to open
its recording.

## A matrix run

![A matrix run: the invariant broke under 3 of 9 faults, shown as a grid](/docs/dashboard-matrix-run.png)

The grid has a row per call or webhook, and a column per fault kind. Red cells broke your invariant.
Click one to see why, then **Watch this trial** to open its recording.

## Insights

![The Insights page: flake rate, slowest and costliest tests, and the replay cache](/docs/dashboard-insights.png)

Sort the table by flake rate, median time or spend to find the tests worth fixing first.

## Every page has a link

Every page, filter and open recording has its own address. **Copy link** in the top bar copies it,
so you can send a teammate the exact trial you're looking at.
