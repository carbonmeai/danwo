danwo needs Node 24 or later. It runs your app in a browser through Playwright, and on an Android
emulator for [mobile apps](/docs/tools/mobile).

## Add danwo to the project

```sh tab="npm"
npm install --save-dev @danwo/sdk @danwo/cli
npx playwright install chromium
```

```sh tab="pnpm"
pnpm add --save-dev @danwo/sdk @danwo/cli
pnpm exec playwright install chromium
```

```sh tab="bun"
bun add --dev @danwo/sdk @danwo/cli
bunx playwright install chromium
```

## Set it up

```sh
npx danwo init
```

`danwo init` sets danwo up in the project, including its MCP server and skill for Claude Code,
Cursor and Codex, so a coding agent can write, run and fix danwo tests for you. Run
`npx danwo init --help` to see every choice it makes and the flags that make it without asking.

## A model for agent steps

Locator steps need no model. Agent steps (`agent.act`, `agent.assert`, `agent.extract`) need one
the first time they run; after that they replay from the cache with no model calls. A model id
such as `"anthropic/claude-sonnet-5"` in the config goes through the Vercel AI Gateway with
`AI_GATEWAY_API_KEY` from the environment. danwo reads no `.env` of its own: export the key, or have
your test command load it.
